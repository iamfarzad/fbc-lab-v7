## 2. Data Storage and Retention

### 2.1 During Active Session (up to 1 hour)

- All interaction data stored in encrypted Redis cache (Upstash)
- Voice transcripts, screen analyses, and uploaded files retained temporarily
- Context available for real-time AI responses

### 2.2 After Session Ends

- Conversation archived to secure database (Supabase)
- PDF summary generated with key highlights
- **Raw data deleted after 7 days** (voice recordings, screen captures, original files)
- **PDF summary retained for 90 days** for follow-up purposes
- **Audit logs retained for 90 days** for compliance

### 2.3 Data Deletion

- WAL (Write-Ahead Log) entries: 7 days
- Voice transcripts and visual analyses: 7 days
- PDF summaries: 90 days
- Audit logs: 90 days
- After retention period: **Automatically deleted**

## 3. Security Measures

We implement enterprise-grade security:

- **Encryption in Transit:** All data transmitted via HTTPS/WSS (TLS 1.3)
- **Encryption at Rest:** All database storage encrypted (Supabase AES-256)
- **Write-Ahead Logging:** 99.9% data reliability guarantee
- **PII Detection:** Automatic detection and redaction of sensitive information
- **Audit Trail:** All data operations logged for compliance
- **Access Control:** Row-Level Security (RLS) on all database tables
- **Infrastructure:** SOC2 Type II compliant hosting (Vercel, Supabase, Fly.io)
